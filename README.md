# BibleAtlas 3

성경 시대의 무대를 **실제 고도와 정직한 확실성 표기**로 그리는 지도.

## 이 저장소가 담는 것

**코드만 담는다.** 자료는 `~/bibleatlas3-data` 에서 만들고, 여기에는 **구운 산출물**만 `data/` 로 들어온다.
원본(raw)과 변환기는 이 저장소에 두지 않는다 — 그래야 "이 화면은 무엇으로 만들어졌는가" 를 한 줄로 말할 수 있다.

## 선행 버전에서 물려받지 않는 것

버전 2(`parkminhyun0/bible-atlas2`)는 2026-09-17 에 멈췄다. 그 구조를 그대로 물려받지 않는다.

| 버전 2 | 버전 3 |
|---|---|
| 단일 HTML 한 덩어리 | `<script type="module">` 로 나눔 (번들러 없음) |
| 도로 자료 20 MB 를 통째로 파싱 | 타일로 잘라 화면에 보이는 것만 |
| 스타일이 코드 안에 박힘 | 스타일을 **자료로** 다룸 — 레이어를 하나씩 끄며 범인을 좁힐 수 있게 |
| 확실성이 자료에만 있고 화면엔 없음 | 확실성이 **선종·`?`** 로 화면에 나타남 (22번 문서 규약) |
| 시각 회귀 시험 없음 | `test/render/` — 스크린샷 픽셀 비교 |

까닭은 노션 **19번**(버전 2 가 멈춘 자리)과 **21번**(제작 공정)에 적혀 있다.

## 굳힌 규칙

1. **권리 확인 전에는 내려받지도 화면에 올리지도 않는다.**
2. **모르는 것은 비워 둔다.** `unlocated` 면 도형을 갖지 않는다.
3. **대안을 하나로 합치지 않는다.** 시내산·소돔처럼 후보가 여럿이면 나란히 둔다.
4. **모든 소스에 `maxzoom` 을 명시한다.** 기본값 22 로 두면 없는 줌을 만들어 내려다 죽는다.
5. **런타임에 큰 GeoJSON 을 파싱하지 않는다.** 버전 2 가 아이폰에서 죽은 자리다.
6. **측정·계산은 언제나 수직 과장 1.0× 기하로.** 화면의 과장은 표시에만 쓴다.

## 띄우기

정적 파일뿐이라 서버가 필요 없다. 다만 `type="module"` 은 `file://` 에서 막히므로:

```
cd ~/bibleatlas3 && python3 -m http.server 8080
```

`http://localhost:8080` 을 연다.

## 배포한 뒤 최대 10분은 옛 화면이 보인다

GitHub Pages 는 `Cache-Control: max-age=600` 을 보낸다. `scripts/stamp_version.py`
가 모듈 주소에 `?v=<해시>` 를 찍어 **모듈**은 바로 새것을 받지만,
**`index.html` 자체가 캐시되어** 그 안의 옛 도장을 10분 동안 계속 가리킨다.

그래서 배포 직후 화면이 그대로여도 실패가 아니다. 확인하려면 서버의 것을 본다:

```js
// 브라우저 콘솔에서 — 페이지가 쓰는 도장과 서버의 도장을 맞대어 본다
const page = document.querySelector('script[type=module]').src.match(/v=(\w+)/)[1];
const html = await (await fetch('index.html', {cache:'reload'})).text();
console.log(page, html.match(/main\.js\?v=(\w+)/)[1]);
```

두 값이 다르면 **서버에는 새것이 있고 브라우저가 옛것을 쥐고 있는 것**이다.
강제 새로고침(Cmd+Shift+R)하거나 기다리면 된다.
